  • Router → 병렬 Tool Agents → Idea Agent의 3단계 파이프라인 설계: Router가 사용자 입력을 분석해 모드를 분류하고 필요한 Tool만 선택적으로 활성화 → character_writer(이름·성격·말투·외모·배경) / narrative_designer(세계관·배경사건·로어북 시드) / relationship_designer(유저-캐릭터 관계·긴장감)를 asyncio.gather로 병렬 실행 → Idea Agent가 결과를 통합해 스트리밍 응답

  • 일반 대화에도 3개 Tool을 모두 실행하면 비용이 낭비되는 문제 → Router의 선택적 Tool 활성화로 호출 최소화
  • 에이전트 간 dict 전달 시 파싱 실패 위치 추적이 어려운 문제 → Pydantic(Concept, ToolContext) 모델로 스키마를 고정해 구조화 데이터를 타입 안전하게 전달
